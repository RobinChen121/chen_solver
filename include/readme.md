This folder contains public headers for users.

- `chen_solver/config.h`: common types and constants
- `chen_solver/core/variable.h`: variable definition
- `chen_solver/core/linear_term.h`: linear term definition
- `chen_solver/core/linear_constraint.h`: linear constraint definition
- `chen_solver/core/model.h`: public model API
- `chen_solver/io/read_file.h`: LP/MPS reader API
